# Security Policy

Сообщайте о проблемах безопасности через приватный GitHub Security Advisory репозитория. Не публикуйте рабочие эксплойты и чеки с персональными данными в открытых issues.

Приложение является статическим PWA: фотографии обрабатываются локально в браузере. OCR-модель загружается с публичных CDN jsDelivr и Project Naptha.
