# Вклад в проект

Спасибо за интерес к «По Чеку».

1. Создайте fork и отдельную ветку.
2. Запустите `node scripts/check.mjs`.
3. Проверьте интерфейс на ширине 375–430 px.
4. Не добавляйте серверную отправку фотографий без явного согласия пользователя и обновления раздела о конфиденциальности.
5. Откройте Pull Request с описанием пользовательского сценария и результатов проверки.

Для ошибок OCR приложите обезличенный пример распознанного текста. Не публикуйте чеки с персональными или платёжными данными.
